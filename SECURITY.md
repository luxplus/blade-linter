# Security Policy

## Supported versions

Only the latest release on the `main` branch receives security fixes.

## Reporting a vulnerability

Please do not open a public issue for security problems.

Report vulnerabilities privately through GitHub's private vulnerability reporting:

https://github.com/luxplus/blade-linter/security/advisories/new

Include a description of the issue, steps to reproduce, and the affected version or commit. You will receive an acknowledgement within a few business days, and we will coordinate a fix and disclosure timeline with you.
